# WebTest Atlas 产品需求

## 产品概述

为日常测试 Web 管理后台的人员提供一个可以持续学习站点的功能测试助手。用户一次配置测试环境、账号和允许操作范围，经 DeepSeek Harness（DSH）对话发出任务。Agent 自行探索、保存知识、执行测试和提供证据。已有流程能复跑，导出的脚本能独立运行。

MVP 在本地运行，服务于单用户和单项目环境，使用 Chromium 与一个测试账号。重点覆盖管理后台的查询、详情、表单及新建流程。接口范围是页面实际调用或用户明确提供的接口。通过 DSH 插件接入测试能力，沿用宿主的对话入口。需求来源为用户在 Codex 中提供的说明与原始需求文档。

## 使用流程

1. 配置站点 URL、环境、测试账号和允许的操作。Agent 登录并开始探索。遇到验证码或 MFA 时由用户完成这一步，随后继续。
2. 在对话中说明测试流程和预期，例如“测试申请列表的查询，覆盖查到已有申请和无结果的情况”。
3. Agent 复用已有知识或脚本，按需补充探索，执行并展示结果与证据。用户可补充预期、要求生成脚本或停止当前任务。
4. 用户需要时查看历史、导出脚本，或在新对话中说“重跑上次保存的申请流程”。

## 功能详情

### F001｜站点接入与恢复登录

- 用户配置站点、环境、测试账号和操作范围。凭据通过独立入口保存。首次配置后 Agent 自动登录并开始探索。配置的授权范围持续生效。
- 已有登录态可用时复用。过期时在预算内恢复。遇到验证码、MFA 或必要权限缺失时，说明用户要完成的操作与恢复入口。
- **验收**　配置示例站后可进入登录后的页面。重启后可使用有效登录态。模拟过期、人工登录挑战和不可恢复登录失败，可分别恢复、等待人工继续或得到带原因的阻塞结果。

### F002｜自动探索与请求观察

- 在当前账号可访问且用户授权的范围内探索导航、页面、表单、按钮和基础流程。采集页面操作与实际业务请求的关系。默认浏览和查询，写操作使用已授权的测试范围。
- 时间和步骤预算可配置。探索显示简短进度。到达预算或用户停止时保留已获结果，并说明未覆盖范围。
- **验收**　示例后台的列表、详情和查询表单可识别。查询动作可关联到实际请求。重复导航有界，预算耗尽或停止后可继续使用已保存的发现。

### F003｜项目知识维护

- 自动保存页面入口、操作定位、流程关系、接口样例、数据依赖、来源、证据和验证时间。用户提供的业务预期与纠正持续生效。
- 对站点当前表现记录观察事实，对业务预期记录用户或明确依据给出的规则。用户按需查看或导出，平时由系统维护。
- **验收**　新对话和应用重启后能复用已有信息。用户补充的查询规则会在后续任务中用于断言。观察到的结果出现在证据中，缺少依据的业务预期标为未判定。

### F004｜对话执行 UI 测试

- 用户描述测试流程和预期。Agent 操作真实页面，进行可定位的步骤验证，报告业务结果及证据。
- 经授权的写流程使用独立测试数据，记录自身创建的对象，按授权清理并报告清理结果。发生超时或部分失败时保留已知结果与待处理信息。
- **验收**　对话可完成列表命中、无结果及一条新建后查询的流程。在示例站启用已知业务错误后，相同断言准确失败并指向相应步骤。清理只作用于本次记录且获准清理的对象。

### F005｜对话执行接口测试

- 针对已观察或用户明确给出的接口，准备参数和鉴权，执行真实请求，按给定规则验证状态和业务响应。参数和响应证据脱敏后展示。
- **验收**　至少从对话完成一个实际接口测试。状态和响应字段可独立判定。鉴权或环境不可恢复时显示阻塞，返回内容违反明确规则时显示断言失败。

### F006｜UI 与接口脚本生成、验证、导出

- 从用户描述或真实执行过的流程生成脚本。脚本包含必要的数据准备、步骤、断言和适用的清理。实际运行后可以保存及导出。用户能在 DSH 之外按说明运行。
- **验收**　UI 和接口各有一份经过实际验证的可导出脚本。在相同环境和数据条件下重复独立运行，检验同一业务预期。脚本和样例只使用凭据引用。

### F007｜复跑与变更适配

- 优先查找已验证知识与脚本，缺口通过局部探索补足。网站变化时更新受影响的内容。
- 可调整等价定位和等待方式。保留原始失败、修改和复验记录，保持原步骤、断言和业务预期。恢复和复验使用有限预算。
- **验收**　新对话或重启后用已保存的脚本复跑。同一按钮的等价定位变化可局部修复。注入业务错误时，原断言仍失败。

### F008｜进度、停止与结果历史

- T001 先验证本地示例页的读取和历史。对话显示运行 ID、观察到的标题、页面标志及带时间的步骤。新对话按 ID 查询原记录。成功读取仅代表获得页面证据，业务断言由后续任务建立。
- 对话显示任务当前阶段、结论、失败原因和关键证据，支持停止、查看历史和重新运行。
- 结论涵盖通过、断言失败、执行错误、阻塞及未判定。已停止任务显示停止状态和已有证据。截图、执行记录或接口证据可追溯到对应任务及步骤，并按需要脱敏。
- **验收**　可停止长任务、查看保留结果并重新运行。可从历史定位一次断言失败的步骤与证据。无预期、执行异常及登录阻塞分别显示对应结果。

## 通用要求与待细化

- 仅当登录、权限、授权范围或关键预期等问题阻塞当前任务时打断用户。探索、执行和修复各自有预算。
- 密码、Token、Cookie 独立管理。知识、普通日志、脚本、公开代码和对话证据使用脱敏信息。
- 随可运行版本交付源代码、启动说明、配置示例和使用示例。
- 随对应功能确认实际验收站点、其登录方式和写流程的授权边界。首轮可用本地示例后台进行可重复的独立验收。
